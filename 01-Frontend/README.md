# GDG AAUP — React + Vite

مشروع React كامل وقابل للتعديل، بواجهة عربية RTL لفرعي جنين ورام الله. يحتوي على كل ملفات المشروع الأصلي، والميزات السابقة، والتحديثات الجديدة. **لا تحتاج إلى إنشاء مشروع Vite جديد أو الوصول إلى مستودع كي تبدأ.**

## ابدأ هنا في VS Code

1. استخرج ملف ZIP وافتح المجلد `gdg-react` الذي يحتوي على `package.json`.
2. استخدم Node.js 22 أو 24، وافتح Terminal داخل VS Code.
3. نفّذ:

```bash
npm ci
npm run dev
```

افتح الرابط الذي يظهر في الطرفية، عادةً `http://localhost:5173`. عدّل ملفات `src/` واحفظ لترى التغييرات مباشرة. لا تعدّل ملفات `dist` لأنها ناتجة عن البناء.

```bash
npm test                # اختبارات قواعد النظام
npm run build           # نسخة إنتاج Vite داخل dist/
npm run preview         # معاينة نسخة الإنتاج
npm run build:single    # ملف HTML واحد داخل dist-single/gdg-evaluation.html
npm run dev:esbuild     # طريقة التطوير البديلة الأصلية
```

`node_modules` لا يأتي داخل ZIP: يُنشئه `npm ci` من ملف القفل المرفق. تحتاج الإنترنت لتنزيل الحزم أول مرة. نسخة HTML الجاهزة موجودة أيضًا في `demo/gdg-evaluation.html` للتجربة السريعة؛ المصدر الكامل هو `src/`.

## قواعد التقييم

- 15 بندًا بأسماء مؤقتة `cat1` إلى `cat15`.
- أول خمسة بنود: أعداد صحيحة من **0 إلى 10**. العشرة الباقية: من **0 إلى 5**. الحد النهائي **100**. لا قيم سالبة، ولا بنود ناقصة، ولا تعديل للحدود من السياسات.
- بطاقة واحدة معتمدة لكل شخص وشهر. تعديلها ينشئ إصدارًا موثقًا؛ أحدث إصدار يحل محل السابق في المجموع، ولا تُجمع الإصدارات.
- المنظّم يقيّم أي حساب فعّال في الفرعين باستثناء نفسه، بما في ذلك المديرون والمنظّمون الآخرون.
- المدير يقيّم الأعضاء فقط، بشرط نفس الفرع ووجود فريق مشترك يديره. العضو يقرأ تقييمه وترتيب الأعضاء ولا يقيّم أحدًا.
- ترتيب الأعضاء: المجموع، ثم مجموع `cat1–cat5`، ثم وقت آخر إصدار معتمد الأقدم، ثم الاسم ثم المعرّف. هذه قاعدة حسم تعادل موثقة يمكن للفريق مراجعتها لاحقًا.
- لوحة الترتيب والتكريم تخص الأعضاء؛ تقييمات المديرين والمنظّمين متاحة لهم في صفحة بطاقات التقييم.
- إغلاق الشهر يحفظ لقطة الترتيب ويبدأ الشهر التالي دون تقييمات. لا تعدّل بطاقة شهر مقفل.

## التكريم والأخبار والصور

من «نجوم الشهر» اختر الفرع والشهر، ثم اختر واحدًا من متصدّري الفرق الأربعة. يظهر اسمه وصورته في صفحة المجتمع تلقائيًا. يوجد تكريم مستقل **لكل فرع وشهر**. إذا تغيّر ترتيب الشهر الجاري وصار الفائز خارج المتصدّرين، يختفي التكريم الجاري حتى يختار المنظّم فائزًا مؤهلًا. التكريم المؤرشف يحتفظ باللقطة التاريخية.

من «الأعضاء» → «تعديل» ارفع صورة العضو. تُقص الصورة إلى مربع وتُصغّر للحفظ. الأحرف الأولى تظهر إن لم تُضف صورة. من «أخبار المجتمع» أنشئ خبرًا واحفظه كمسودة أو انشره؛ المنشور فقط يظهر للزوار.

تبديل جنين/رام الله يغيّر الصورة الخلفية. صور الفرعين المرفقة مضمّنة في المشروع. روابط To Do وواتساب وديسكورد تفتح في تبويب جديد لجميع الأدوار.

## الحفاظ على الميزات السابقة

سجل النقاط الحرّة الأصلي محفوظ في «سجل النقاط القديم»، مع الإضافة والعكس والتصحيحات المتأخرة. لا يغيّر ترتيب التقييمات الجديدة. تقييم المديرين الإداري القديم ومعاييره محفوظ كميزة منفصلة؛ لا يغيّر حدود البنود الـ15. إدارة الحسابات والفرق والسياسات والأرشيف وسجل التدقيق وسجل النظام والمساعد والوضع الداكن ومحاكاة الأخطاء ما زالت موجودة. بيانات الإصدار السابق تُرحّل مع الحفاظ على السجلات القديمة؛ لا تُختلق لها تقييمات جديدة. معلومات توزيع العمل الأصلية محفوظة في `docs/ORIGINAL_README.md`.

## ما الذي يعمل محليًا، وما الذي يحتاج خادمًا؟

هذا **مشروع واجهة أمامية كامل ببيانات تجريبية محلية، وليس نظامًا بخادم وقاعدة بيانات مشتركة**. البيانات تبقى في localStorage للمتصفح، والتبويبات على نفس الأصل تتزامن. لا تتزامن الأجهزة أو المتصفحات المختلفة. ملف HTML المستقل وخادم Vite قد يستخدمان مساحات تخزين مختلفة.

الصلاحيات منفذة في محرك التجربة ومختبرة، لكنها ليست حماية أمنية في الإنتاج لأن كل شيء محلي. قبل استخدامه مع أعضاء حقيقيين، يجب على مطوّر الخادم تنفيذ المصادقة والصلاحيات والتحقق وحفظ البيانات على الخادم وفق `docs/API_CONTRACT.md` و`docs/RATINGS_API.md`، ثم ضبط:

```env
VITE_USE_MOCK=false
VITE_API_URL=https://your-backend.example/api
```

لا يكفي تغيير المتغير دون توفير الخادم. التكامل مع خادم فعلي لم يُختبر. للأخبار والتكريم عبر أجهزة متعددة أضف تحديثًا دوريًا أو قناة أحداث من الخادم. لا توجد خدمة إرسال إشعارات فعلية؛ قائمة الجرس تعرض إرشادات. المساعد الأصلي قائم على قواعد محدودة وليس خدمة ذكاء اصطناعي خارجية.
